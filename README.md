📥 Media Utility App

A modern Android media utility app that enables users to securely download and manage Instagram stories, reels, and posts for offline access.

Built with a scalable and secure architecture, this app leverages the latest Android technologies to ensure performance, maintainability, and robust data handling.

🚀 Features

📌 Download Instagram stories, reels, and posts

🔒 Secure offline storage with SQLCipher encryption

📂 Built-in media manager for organizing downloads

⚡ Powered by Coroutines & Flows for responsive UI updates

🏗️ Clean MVI architecture for scalability and maintainability


🛠️ Tech Stack

Architecture: MVI (Model-View-Intent)

Dependency Injection: Hilt

Database: Room
 with SQLCipher
 for secure storage

Concurrency: Kotlin Coroutines & Flows
